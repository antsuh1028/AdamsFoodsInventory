Scan Station Test Labels

Real GS1-128 box labels with made-up products, for testing Lot Registration and the scan station on a test database. Every label here was read by the server's own barcode parser before this page was made, so the "Expect" line is what the app will actually do. Print the page, or scan straight off a screen if your scanner reads screens.

Before you start

  1. Use a Neon branch of the database, never production. Start the server with DB_CONNECTION_STRING='…branch…' npm start.
  2. On the tablet: Lot Registration, register two lots (call them lot 1 and lot 2), add an item to each, then Connect to receiving station.
  3. On the station computer: Scan Station open and focused, scanner plugged in.
  1. Point the station at lot 1 and work through the groups in order. Group B also needs lot 2.
  2. Every label carries a red TEST tag. The products are made up, so never stick these on real boxes.

Keypad tests (no label needed)

Do this on the tabletExpect
Keypad: type 40.00, Add box. Then type 40.00 again."Same weight as the last box." Same box, don't add adds nothing; Different box, add it adds it.
After the ten group A boxes are on the item, type 411."Is that weight right?" about 10× heavier. Let me retype puts 411 back on the keypad.
Type 4.1 on the same item.The same question, about 10× lighter.
Copy the printed numbers from any card in group A into Barcode will not scan?, with or without spaces, then Add box.On a fresh lot it lands with the yellow typed badge and keeps its serial. If that box is already on another lot, it is refused like a scan.
Press Enter on the scanner while a question is open.Nothing is added: focus is on the safe button.
