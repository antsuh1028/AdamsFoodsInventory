ES

Tarima llena: espere todo guardado y toque Terminar sesión (rojo). Deje marcada Imprimir la etiqueta. Esto cierra la tarima, no el lote.

EN

Pallet full: wait for all saved, then tap Stop session (red). Keep Print the pallet tag ticked. This closes the pallet, not the lot.

5

Etiqueta / Pallet tag

1Se queda aquí · Stays here
✂ Cortar aquí · Cut here
2Va con el chofer · Goes with the driver
ES

Salen dos etiquetas en una hoja. Corte en la línea punteada: una se queda aquí y la otra va con el chofer. ¿No se abrió? Permita ventanas emergentes.

EN

Two tags print on one sheet. Cut on the dashed line: one stays here, the other goes with the driver. Nothing opened? Allow pop-ups.

Si la pantalla pregunta / If the screen asks

Exactamente igual que la caja anterior · Same as the box before
Misma caja — omitirlaSame box — skip it Registrar 41.25 lbRecord 41.25 lb
ES

Mismo peso que la anterior: si es la misma caja (etiqueta rota o repesaje), toque Misma caja — omitirla; si es otra caja, regístrela. Mucho más pesada o ligera: revise el punto decimal. ¿Caja equivocada? Deshacer la última.

EN

Same weight as the last box: if it is the same box (torn label or re-weigh), tap Same box — skip it; a different box, record it. Much heavier or lighter: check the decimal point. Wrong box? Undo last.
